# Uruchamianie
## Zależności
### Przy użyciu uv
```
uv venv &&
source .venv/bin/activate
uv sync
```

### Przy użyciu pip
```
python -m venv venv &&
source .venv/bin/activate &&
python -m pip install -r requirements.txt
```

## Uruchamianie skryptu
```python
python -m src.main
```
